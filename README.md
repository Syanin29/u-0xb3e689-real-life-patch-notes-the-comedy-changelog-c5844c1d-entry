One patch note about a bug in real life / human biology, written to
`/output/entry.txt` by a tiny deterministic Python program — no network,
no randomness, no model calls; both runs write the same bytes.

> v2.4.1: fixed a bug where the body woke up one minute before the alarm, every day, just to check the alarm still worked.

120 characters, inside the 1–160 gate. See `brainstorm.md` for the 12
candidates, pairwise scoring, and why this one was picked.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
